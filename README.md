# Auth & Password Strength App

A full-stack authentication web application with real-time password strength inspection and user management.

## 🚀 Deployments

- **Live Demo**: [https://loginpage-production-cf191c24.up.railway.app/](https://loginpage-production-cf191c24.up.railway.app/)
- **Platform**: [Railway](https://railway.app/)
- **Status**: Active (HTTP 200 OK)

---

## ✨ Features

- **User Registration & Login**: Account creation and authentication with input validation.
- **Real-Time Password Inspector**: Live password strength analysis, dynamic scoring, and suggestions.
- **Security**: Password hashing using `bcrypt` (12 salt rounds).
- **Interactive UI**: Reactive visual feedback that adapts to password quality in real-time.

---

## 🛠️ Tech Stack

- **Backend**: Node.js, Express.js
- **Security & Libraries**: `bcrypt`, `password-inspector`
- **Frontend**: HTML5, Vanilla JavaScript, CSS3

---

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/akshatjoddd/login_page.git
   cd login_page
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the application:**
   ```bash
   npm start
   ```

4. Open your browser and visit: `http://localhost:3000`
